Choose which paired computer this AI session controls.

Call switch_computer with no arguments to list paired devices, their IDs, platforms,
connection state, and the session's current explicit target. This only reads the
control plane; it never moves the pointer or requests POINTER approval.

To switch, pass computerId with the exact device ID from that list. An exact
computer name or an unambiguous platform (macOS, Windows, Linux) also works.
Unknown, ambiguous, offline, denied, or cancelled choices leave the previous target
intact. A successful switch overrides the automatic/default device for this
session and persists with the session. Other sessions keep their own targets.

Every subsequent computer_* tool targets the selected device, including observe,
snapshot, apps, actions, plans, screenshots, and browser automation. The server URL
and credentials stay unchanged. This selects a device served by the current
control plane, not a different server. It grants no permissions and does not
launch an application by itself.

A successful switch reports computerId, the new device's accessibility state, and
freshObservationRequired. It reads the new device once, so the session holds a live
observation for it (observationId and generation) that computer_snapshot can page
with sinceGeneration. When freshObservationRequired is true, that tree is degraded
or was unreadable: confirm with computer_screenshot and ground with
computer_visual, and treat every control not in the tree as unseen.

Observations and refs do not travel between computers. The switch invalidates every
observation this session read off the device left behind, so after a switch always
take a fresh computer_snapshot on the new device before acting: a ref, observation
ID, coordinate, or browser tab ID from the previous computer is refused with the
name of both computers, and never resolved against the new device's element list.

Finish any in-flight computer action before switching. Do not run this tool in
parallel with actions against the old target.

If the new device disconnects, report that failure rather than silently using
another paired computer.

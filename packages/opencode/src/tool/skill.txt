Load a specialized skill when the task at hand matches one.

The skill catalog is not included in the system prompt. Call this tool without a name to list available skill names, with `query` to search skill names and descriptions, or with `name` to load a skill's instructions.

The output may contain detailed workflow guidance as well as references to scripts, files, etc. in the same directory as the skill.

Do not guess a skill name. List or search first, then load the matching skill.

Run an autonomous discussion room for a topic.

A discussion room is a meeting of a manager and a roster of specialists (four by default; Pro and above can customize). The manager frames the problem, the specialists give positions in rounds, the manager synthesizes a decision and assigns one concrete piece of work to each specialist, and then every specialist breaks off to execute its assignment — spawning its own subagents when the work splits into independent parts.

Use this tool when a task needs a real decision plus parallel execution: strategy calls, architecture choices, research plans, launch plans, incident postmortems, or any request that benefits from several independent viewpoints converging before work starts.

The room runs to completion in one call. It returns the manager's decision, the assignments, and each specialist's work report, with the session id of every participant so their full transcripts can be opened afterward. Only use it in Agent mode; it is not available in Code mode.

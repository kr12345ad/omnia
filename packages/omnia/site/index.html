01 / Product

It works in your apps.

Omnia controls the browser, desktop apps and terminal in one session. The run ends when the result is visible on screen or written to disk.

01

Controls your apps

Omnia uses the browser, desktop apps and terminal in one session, including tools with no API.

02

Verifies its own work

After each action, Omnia reads the screen or file back. A step counts as done only when the result is visible in the app.

03

Stops for approval

Payments, deletes and other irreversible actions wait for your approval. The exact scope is shown before anything runs.

04

Stays on your machine

Sessions, files and credentials stay on your computer. The model receives only the context needed for the current step.

05

Bring your own model

Use a hosted provider or a local OpenAI-compatible endpoint. You can switch models between sessions.

06

You can take over

Each session shows a live desktop. You can take the mouse, type or pause the agent, then let it continue from that point.

03 / Trust

You set the limits.

Omnia asks for capabilities per session and shows the scope of a sensitive action before it runs. You can deny any request.

Capabilities are granted per session
01

Explicit grants

Each session gets grants for files, process, browser and network. Omnia cannot use a capability you did not grant.

02

Credentials stay in the vault

The runtime types stored credentials into the app. They are not placed in the model context and do not appear in logs.

03

Sensitive actions wait

Irreversible actions and anything that moves money pause with the exact scope on screen. Deny one and the agent stops that path.

04

Local transcript

Every command, file and approval is recorded in a transcript on your machine. You can export or delete it.

06 / Questions

What runs where.

Answers about data, models, ads and limits.

What can Omnia do?

Within the permissions you grant, Omnia can fill in a portal, reconcile a spreadsheet, file receipts, run a deploy or collect research across tabs. It stops at any approval boundary you set.

Does it work with the apps I already use?

Yes. Omnia controls the browser and desktop you already use, including internal tools, legacy apps and sites without APIs.

What leaves my machine?

The current request and the context needed for the step go to the model provider you choose. On Free, the latest request text and a random session id also go to our ad service to pick a sponsor card. Files and credentials stay on your machine.

How is the ad chosen?

Gravity matches the request text to a sponsor. The card is labelled Sponsored and has one outbound link. It does not appear in files, tool results or approval prompts.

Can I use a local model?

Yes. Point Omnia at a local OpenAI-compatible endpoint. Sessions, approvals and tools work the same way.

Which platforms are supported?

macOS 13+, Windows 10+ and Linux x64. One account and plan work on all three.

What happens when I hit a limit?

The session pauses and shows the limit. Nothing is charged automatically. You can upgrade if you want to continue.
